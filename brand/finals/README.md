# Wardrobe Cart mark

Selected by the user: **B · Open Door**.

The sky-blue cart basket is made from two wardrobe doors. One door opens into the cart's front
wall; the dusty-terracotta hinge is CBC's spending gate. The basket is empty because CBC starts
with what the user owns.

Palette: white `#FFFFFF`, sky blue `#69BCEB`, dusty terracotta `#D98268`.

The earlier Proof Seam, Gate Monogram, and unselected Wardrobe Cart candidates remain in `renders/`
as exploration history. They are not production assets.
